THE SIMPLE START

Your personal player.

Serve the static app and connect a working Invidious or Piped instance for search and playback.

Quick start 
git clone https://github.com/YossiYad/aura.git
cd aura
python3 -m http.server 8477

Requires Git and Python 3. Open localhost:8477, then configure your instance in Settings.

A FEW GOOD QUESTIONS

Before you hit play.

Where does the music come from?+

Aura uses the Invidious or Piped instances you configure for search and playback. It does not include a licensed music catalog. Instance availability varies. Use content you are permitted to access and download, and follow the relevant service terms.

Do I need AI to use Aura?+

No. Search, playlists and playback work without an AI key. AI playlist generation uses your own Gemini or Groq key. Voice recognition depends on your browser and may use its speech service.

Is there a hosted demo or an app-store download?+

This site introduces the project. Set up your own Aura instance using the guides above, then install it from your browser. There is no official public demo or native app-store package linked here.

What data leaves my device?+

Your library is local by default. Search, playback, artwork and optional AI or speech features contact their providers. Self-hosted sync stores your library metadata on your server. Read the privacy notes for details.
